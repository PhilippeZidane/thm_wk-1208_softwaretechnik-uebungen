# Anforderungen — Terminplaner für die THM


| Nr. | Anforderung | Stakeholder | Art |
|---|---|---|---|
| A01 | Das System muss Studierenden ermöglichen, verfügbare Sprechstundentermine bei Lehrenden einzusehen. | Studierende  | FA |
|A02 | Das System muss Studierenden ermöglichen, einen verfügbaren Termin verbindlich zu buchen.| Studierende | FA| 
|A03 | Das System muss Lehrenden ermöglichen, ihre verfügbaren Sprechstundenzeiten selbst festzulegen.|  Lehrende | FA|
A04|   Das System muss verhindern, dass ein Termin gleichzeitig von mehreren Personen gebucht wird. | Studierende und Lehrende | FA|
A05 | Das System muss verfügbare Termine bei normaler Systemauslastung innerhalb von zwei Sekunden anzeigen.| Studierende | QA |
| A06| Das System muss persönliche Termindaten vor unberechtigtem Zugriff schützen.| Datenschutzbeauftragte| QA|
A07|  Die Anmeldung zum Terminplaner muss über die bestehenden Hochschulkonten der THM erfolgen.| Hochschul-IT| RB|
| A08 | Das System muss die geltenden Datenschutzvorschriften bei der Verarbeitung personenbezogener Daten einhalten.| Datenschutzbeauftragte | RB |

## Eine Anforderung, die niemand ausgesprochen hat



**A06 – Verhinderung von Doppelbuchungen**

Diese Anforderung ist notwendig, damit ein Termin nicht gleichzeitig an mehrere Studierende vergeben wird. Sie wurde möglicherweise im Gespräch nicht ausdrücklich genannt, weil die Beteiligten davon ausgehen, dass ein Terminplaner Doppelbuchungen automatisch verhindert.
